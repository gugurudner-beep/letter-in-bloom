# Letter In Bloom

Crie um protótipo visual interativo premium inspirado nas capturas anexadas.

Não reconstrua o site inteiro. Desenvolva apenas esta experiência:

1. um envelope romântico fechado;

2. uma interação suave para abrir o envelope;

3. a revelação de uma Polaroid com espaço vazio para fotografia;

4. a abertura de uma carta elegante com texto demonstrativo neutro.

Use as capturas como referência direta de identidade visual.

Objetivo: melhorar significativamente o acabamento gráfico, mantendo o estilo romântico editorial já existente.

Quero:

- papelaria mais realista;

- sombras mais naturais e sofisticadas;

- melhor profundidade visual;

- Polaroid mais convincente e refinada;

- carta mais elegante, delicada e premium;

- microinterações suaves;

- excelente aparência no celular.

Paleta:

- marfim;

- rosé suave;

- detalhes discretos em bordô.

Estilo:

- romântico adulto;

- sofisticado;

- íntimo;

- nostálgico;

- editorial;

- delicado, sem exageros.

Importante:

- não invente fotos de casais;

- não reconstrua o site completo;

- não implemente perguntas, mural, retrospectiva ou outros capítulos;

- não adicione backend, autenticação ou banco de dados;

- foque apenas nesse protótipo visual.

Entregue uma demonstração funcional, mobile-first, com componentes bem organizados e visual de altíssima qualidade.
